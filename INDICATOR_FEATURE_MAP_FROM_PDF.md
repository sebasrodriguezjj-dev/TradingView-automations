# PDF Feature Map

Fuente analizada: `C:\Users\sebas\Downloads\Documento sin título (2).pdf`

## Resumen

El PDF contiene 12 páginas y funciona como una matriz visual de referencia para el indicador unificado. La idea correcta no es inventar un estilo nuevo, sino heredar cada bloque desde su indicador fuente, excluyendo `Money Matrix`.

## Fuente Por Indicador

- `Market Structure Dashboard | Flux Charts`
  - Dashboard principal
  - Dashboard de timeframe actual
  - Dashboard de contexto
  - Dashboard de niveles HTF
  - Trend bias settings
  - Visual overlays
  - Swing labels, swing lines, PDH/PDL, PWH/PWL, PMH/PML
  - Real-time internal structure
  - Real-time swing structure
  - Order blocks
  - EQH/EQL
  - Fair value gaps
  - Premium / discount zones

- `ICT Killzones & Pivots [TFO]`
  - Killzone boxes
  - Killzone labels
  - Killzone pivots
  - Midpoints
  - Day / Week / Month open-high-low separators
  - Session table / averages

- `LuxAlgo - Liquidity Sweeps`
  - Sweep settings
  - Sweep direction colors
  - Sweep area styling
  - Extend / max bars behavior

- `Engulfing Candles`
  - Engulfing shape style
  - Bull / bear shape color
  - Placement above / below bar
  - Visibility / output behavior

- `LuxAlgo - Inversion Fair Value Gaps (IFVG)`
  - IFVG show last
  - Signal preference
  - ATR multiplier
  - Bull / bear / midline colors
  - Visual treatment for inversion gaps

## Decisión De Diseño

El indicador unificado debe heredar:

- `Dashboard`, `overlays`, `swing labels`, `swing lines`, `EQH/EQL`, `premium/discount`, `FVG base`, `order block settings` desde `Market Structure Dashboard`.
- `Killzones`, `pivots`, `session timing`, `calendar/session levels` desde `ICT Killzones & Pivots`.
- `Sweeps` desde `Liquidity Sweeps`.
- `Engulfing` desde `Engulfing Candles`.
- `IFVG visual y inputs` desde `LuxAlgo IFVG`.

Y debe excluir por completo cualquier look o lógica de `Money Matrix`.
