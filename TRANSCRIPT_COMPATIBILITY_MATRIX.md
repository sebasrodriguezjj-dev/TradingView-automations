# Transcript Compatibility Matrix

Use this file as a filter layer for transcript-derived ideas.

Purpose:

- strengthen the existing SMART MONEY - GOOD MONEY strategy
- avoid strategy drift
- separate hard engine rules from coaching-only material

Compatibility rule:

- if a transcript concept reinforces the current strategy, it may be promoted
- if a transcript concept is useful but not strict enough for automation, keep it as coaching
- if a transcript concept conflicts with the current hierarchy, risk model, or execution discipline, ignore it

## Promotion Rules

Only promote a transcript concept if it passes all of these filters:

- reinforces the current strategy instead of replacing it
- respects `Daily/4H -> 30m -> 15m -> 5m`
- improves timing, clarity, or trigger quality
- fits the existing risk model
- does not encourage chasing, blind anticipation, or overtrading

## Coaching-Only Rules

If a concept is useful but too soft for automation:

- keep it in reassessment language
- keep it in Discord's short `why this matters` explanation
- keep it in EOD learning
- do not turn it into a hard workflow gate

## Ignore Rules

Ignore any transcript idea that:

- weakens timeframe discipline
- encourages prediction over confirmation
- ignores the existing risk model
- invites trade-taking without clean liquidity or structural context
- turns the engine into a generic course summary instead of a trading assistant
